# Commit Hours

Приложение для строки меню macOS: часовые интервалы Git-коммитов, плотность работы и предварительная оценка пользы.

**[Скачать последнюю версию](https://github.com/mezhnin/commit-hours-releases/releases/latest)** · **[Установка](https://mezhnin.github.io/commit-hours-releases/)**

Для Mac с Apple Silicon (M1 и новее), macOS 14+. Для чтения репозиториев нужен Git. Intel не поддерживается.

## Установка

1. Скачайте ZIP из последнего релиза и распакуйте.
2. Перенесите `Commit Hours.app` в «Программы». Перед ручной заменой завершите старую копию.
3. Запустите приложение и добавьте свои репозитории через шестерёнку.

Сборка пока не заверена Apple, поэтому macOS может заблокировать первый запуск. После попытки запуска разрешите открытие в «Системные настройки → Конфиденциальность и безопасность». [Инструкция Apple](https://support.apple.com/ru-ru/102445).

Если кнопка разрешения не появляется, для скачанной здесь копии можно снять карантин только с этого приложения:

```sh
xattr -dr com.apple.quarantine "/Applications/Commit Hours.app"
open "/Applications/Commit Hours.app"
```

## Обновления и данные

Начиная с 0.5.0 приложение проверяет новые версии раз в сутки. Ручная проверка: меню «…» → «Проверить обновления…». Отключить автоматическую проверку можно в настройках → «О программе». Установка выполняется по вашей команде с перезапуском.

Обновления загружаются с GitHub и проверяются по цифровой подписи Sparkle. Настройки проектов и история сохраняются. Пути к проектам, авторы и коммиты остаются на вашем Mac; статистика использования не отправляется.

Здесь публикуются только готовые приложения, инструкции и подписанный список обновлений. Исходники находятся в отдельном закрытом репозитории.
