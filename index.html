Commit Hours

Ваши Git-коммиты по часам: интервалы, плотность работы и предварительная оценка пользы. Приложение живёт в строке меню macOS.

Скачать последнюю версию

Apple Silicon · macOS 14 и новее · для чтения репозиториев нужен Git

Первая установка

  1. Скачайте ZIP из релиза и распакуйте.
  2. Перенесите Commit Hours.app в «Программы». Перед ручной заменой завершите старую копию.
  3. Запустите приложение. Откройте «Git: —» в строке меню, нажмите шестерёнку и добавьте свои репозитории.

Сборка пока не заверена Apple. Если macOS блокирует первый запуск, разрешите открытие в «Системные настройки → Конфиденциальность и безопасность». Инструкция Apple.

Если кнопка разрешения не появляется, после переноса скачанного здесь приложения в «Программы» выполните в Терминале:

xattr -dr com.apple.quarantine "/Applications/Commit Hours.app"
open "/Applications/Commit Hours.app"

Следующие обновления

Начиная с версии 0.5.0 приложение проверяет обновления раз в сутки. Установка — по кнопке с перезапуском. Настройки проектов и история сохраняются.

Ручная проверка: меню «…» → «Проверить обновления…». Автоматическую проверку можно выключить в настройках → «О программе».

Ваши данные

Пути к проектам, авторы и коммиты остаются на вашем Mac. GitHub используется для загрузки подписанных обновлений. Статистика использования не отправляется.
